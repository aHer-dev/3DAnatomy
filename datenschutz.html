Zurück zur 3D-App

Allgemeiner Betrieb

Die 3D-Anatomie-App ist eine statische Web-App ohne Login und ohne integriertes Werbe- oder Analyse-Tracking nach aktuellem Projektstand.

Lokale Browser-Speicherungen

Für die Funktion und Bedienbarkeit der App werden lokal im Browser gespeicherte Daten verwendet.

  • Metadaten-Cache im localStorage
  • Zuletzt verwendete Farben im localStorage
  • Weitere funktionale UI-Zustände im Browser

Diese Informationen dienen nach aktuellem Projektstand der lokalen App-Funktion auf dem verwendeten Gerät und werden nicht an einen eigenen Projektserver übertragen.

Öffentliche Bereitstellung

Bei öffentlicher Bereitstellung über GitHub Pages wird die Website über GitHub ausgeliefert. Dabei können technisch notwendige Verbindungsdaten wie IP-Adressen durch den Hosting-Anbieter verarbeitet werden.

Zusätzlich lädt die 3D-App derzeit Teile ihrer 3D-Bibliothek über jsDelivr. Auch hierbei entstehen technisch notwendige externe Abrufe.

  • GitHub Privacy Statement
